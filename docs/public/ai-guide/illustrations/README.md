# 插图与许可

图片许可附件

图片保持各自来源的许可，指南正文不改变它们的许可。MIT、Apache、GPL、CC BY 与 CC BY-SA 全文按项目保留；具体图片署名、原始URL、版本、修改说明与许可依据见来源台账。ComfyUI的GPL图片原始JPG也附在本包内。其余原件见完整资料包中的插图目录。

第三方图形内容未重绘或翻译；部分论文图从PDF裁出，部分SVG转换为PNG，变换已记录。中文导读是本指南的独立说明。

本版正文使用23张插图，其中16张为原论文/官方教学/项目资料，7张为原创教学图；另外7张Mermaid流程图保留在正文源文件。目录中的SVG为部分原创图的可编辑版本。
