# 把财务目标写成可以复盘的计划

“想存一笔钱”和“知道该记录哪些进展”之间，还差一张清楚的目标卡。它的作用是帮助复盘，而不是承诺某种收益。

## 目标卡片模板

| 字段 | 自行填写 |
| --- | --- |
| 目标及用途 | 这笔资金最终用来做什么？ |
| 目标金额与币种 | 金额是多少，是否包含已知费用？ |
| 计划日期 | 到哪一天需要使用？ |
| 当前已安排的金额 | 区分已持有与尚未到账的资金 |
| 约束 | 流动性、家庭责任、其他已承诺支出 |
| 关键假设 | 哪些收入或成本还不确定？ |
| 复盘时间 | 何时重新检查？ |

## 不把假设藏进公式

如果用“差额除以剩余月份”估算每月需要安排的金额，要同时检查收入是否稳定、支出是否有季节性、目标日期是否能调整。这个算式只是进度拆解，不代表某种资产能够提供稳定回报。

## 记录变更原因

目标调整很常见。与其覆盖旧数字，不如保留“原计划、发生了什么、现在怎么改”三列。这样下次复盘能区分执行偏差、信息变化和目标本身改变。

公开笔记可以分享表格结构；真实金额和账户信息留在自己的私密记录中。
