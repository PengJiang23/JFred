# 理财笔记

先把账记清楚，再讨论选择。这一栏用于整理个人财务记录的方法和表格，不提供具体证券、基金或收益预测。

## 从这里开始

- [现金流：先看见钱从哪里来、到哪里去](./cash-flow)：建立可以每月更新的收支表。
- [财务目标：把一个想法拆成可以复盘的计划](./goals)：记录金额、日期、约束和变化原因。

## 记录的原则

区分事实与判断：实际收入、已发生支出和当前余额是事实；未来收入、预期回报和风险承受能力是需要反复检验的假设。公开分享时只保留方法与空白模板，不上传真实账号、账单、身份证明或资产明细。

工具参考：[美国消费者金融保护局的个人财务工具包](https://www.consumerfinance.gov/consumer-tools/educator-tools/your-money-your-goals/toolkit/)，包括收入、支出、账单日历与现金流记录工具。
