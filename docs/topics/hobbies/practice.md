# 给兴趣建一个小档案

兴趣不一定需要目标和成绩，但值得留下一点过程。记录的重点不是展示“完成了多少”，而是以后还能想起当时为什么喜欢、哪里遇到了困难。

## 一次体验的最小记录

| 项目 | 记录内容 |
| --- | --- |
| 时间与主题 | 何时、做了什么 |
| 开始前的想法 | 为什么想尝试 |
| 实际过程 | 哪些细节值得保留 |
| 一个观察 | 与预期相比有什么不同 |
| 下一次 | 想继续、调整或暂停什么 |

照片、作品或附件只挑少量有意义的内容。公开分享前检查是否包含他人的肖像、地址、车牌、行程或其他不希望公开的信息。

## 从单次记录到专题

当同一主题有多条记录后，再建立子目录，例如 `hobbies/reading/` 或 `hobbies/photography/`。目录应跟随真实内容生长，不必一开始就把所有爱好都列出来。

专题首页可以保留三个入口：最近记录、整理后的方法、仍在探索的问题。它们分别回答“最近做了什么”“哪些经验可以复用”和“接下来想知道什么”。
