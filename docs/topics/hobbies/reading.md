# 一份轻量的阅读记录

阅读记录不必变成另一项复杂任务。一个能在几分钟内填完、以后还找得到的模板，通常更容易持续使用。

## 五行模板

```text
名称与作者：
来源、版本与位置：
我带着什么问题开始读：
读完后，我怎样回答这个问题：
下一步想验证或实践什么：
```

对网页记录 URL 与阅读日期；对书籍记录版本、章节或页码。来源有了位置，以后才容易核对，而不只是记住一句离开语境的话。

## 把三种内容分开

- **原文事实**：作者实际写了什么，尽量保留上下文。
- **自己的解释**：我如何理解，与已有知识有什么联系。
- **待验证想法**：还没有证据支持，需要继续阅读或动手测试。

摘录尽量短，更多篇幅留给自己的总结。公开发布时保留署名和链接，避免把整章或大段原文复制到笔记中。

## 定期回看

回看时不必重读所有内容。先看看当时的问题是否仍然重要、下一步是否做过，以及现在的理解有没有变化。有变化就追加记录，比只修改旧结论更能看清学习过程。
